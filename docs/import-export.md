# 导入导出说明

FMS2 支持三类数据交换：

- JSON 备份，用于 FMS2 自身备份。
- 旧 FMS xlsx 导入，用于从旧版 FMS 迁移。
- Excel 导出，用于总榜统计和旧 FMS 兼容格式。

相关实现主要位于：

- `src/repositories/backupRepository.ts`
- `src/repositories/legacyFmsImportRepository.ts`
- `src/repositories/excelExportRepository.ts`

## JSON 备份

JSON 备份由 `createJsonBackup()` 生成，包含当前 IndexedDB 中的主要业务表：

- `people`
- `tags`
- `person_tags`
- `leaderboards`
- `leaderboard_entries`
- `annual_leaderboard_settings`
- `app_settings`

JSON 备份用于当前 FMS2 本地数据备份，不是旧 FMS 兼容格式。

## 旧 FMS xlsx 导入

旧 FMS 导入入口会在浏览器本地解析 xlsx 文件，不上传到服务器。

导入行为：

- 导入前可预览人员数、榜单数、条目数、0 分条目数、标签数和错误。
- 正式导入时，如果文件存在解析错误，会中止导入。
- 正式导入会清空当前 FMS2 本地业务数据，并重建人员、标签、榜单和条目。
- 正式导入也会清空各年的代表人物设置；旧 FMS xlsx 格式不包含该设置。

### 第一个 sheet：榜单数据

旧 FMS 榜单数据使用三列块格式。每期榜单占 3 列：

```text
第 1 行：数字日期
第 2 行开始：姓名、分数
有效人员下一行第 1 列：榜单标题
```

示意：

| A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- |
| 20240101 |  |  | 20240108 |  |  |
| 张三 | 10 |  | 李四 | 9 |  |
| 李四 | 8 |  | 张三 | 0 |  |
| 第一周 |  |  | 第二周 |  |  |

导入口径：

- 数字日期会转换为 `boardDate`，并保留到 `legacyDigitalDate`。
- 姓名会导入为人员。
- 正分数导入为有效榜单条目。
- 行内排名导入为 `rank`。
- 0 分条目不计入有效上榜，通常用于辅助生成出榜记录。
- 每一期标题导入为 `leaderboards.title`，允许为空。
- 导入后会重新计算 `previousRank`、`rankDelta`、`movement` 和出榜条目。

### 第二个 sheet：标签数据

标签 sheet 设计为人类可编辑格式：

```text
第 1 列：颜色块
第 2 列：标签名称
第 3 列起：拥有该标签的人员姓名
```

示意：

| 颜色 | 标签 | 人员 1 | 人员 2 |
| --- | --- | --- | --- |
| 色块 | 男 | 张三 | 王五 |
| 色块 | INFP | 李四 | 赵六 |

导入口径：

- 标签名称为空的行会被忽略。
- 颜色优先读取单元格填充色。
- 后续列中的人员姓名会转换为 `person_tags` 关系。
- 不存在的人员姓名不会创建额外人员，只会跳过该关系。
- 标签顺序按 sheet 行顺序写入 `sortOrder`。

## Legacy xlsx 导出

旧 FMS 格式导出由 `exportLegacyWorkbook()` 生成。

导出内容：

- 第一个 sheet 使用旧 FMS 三列块格式。
- 每个榜单占 3 列。
- 第 1 行写 `legacyDigitalDate`；缺失时由 `boardDate` 或 `createdAt` 转为 `yyyyMMdd`。
- 从第 2 行开始写有效在榜人员姓名和分数。
- 本期有效人数下一行第 1 列写榜单标题。
- 不写出榜记录。
- 不写 0 分记录。
- 第二个 sheet 写标签数据，格式为颜色块、标签名、人员姓名列表。

该格式优先保证旧 FMS 和人工编辑可读性。

## 总榜 Excel 导出

总榜导出由导出页面触发，支持选择人员范围和榜单日期范围。

生成 workbook 包含 3 个 sheet：

### 总榜

首行：

```text
姓名、所选榜单日期列、上榜次数、总点数、加权总点数、加权排名、峰值排名、总榜排名、单周最高排名、单周最高点数
```

规则：

- 每个人员一行。
- 每期分数取有效上榜分数。
- 缺席、出榜或无效记录写 `0`。
- 总榜统计复用 `calculatePersonOverallMetrics()`。
- 人员排序以总榜排名为主，无统计人员排后。

### 位次统计

首行：

```text
姓名、1、2、...、60、0
```

规则：

- 每个人员统计所选榜单范围内各名次出现次数。
- 缺席、出榜、无效记录或超过统计范围的排名计入 `0`。

### 总榜排名走势

首行：

```text
姓名、所选榜单日期列
```

规则：

- 只使用导出页面选择的人员和榜单。
- 榜单按导出日期顺序升序。
- 每一期使用截至当期的所选条目重新计算总榜排名。
- 首次有效上榜前或无排名时单元格留空。
- 总榜排名口径与应用内一致，包括无并列和加权点数决胜规则。

## 冻结窗格

Excel 下载由 `downloadWorkbook()` 处理。导出时会对 workbook 注入冻结窗格，让每个 sheet 冻结首行首列。

因为 SheetJS 社区版对部分样式和视图能力支持有限，当前实现会在写出 xlsx 后处理 workbook 内部 XML。修改导出逻辑时，需要保留冻结窗格和标签颜色写入逻辑。

## 维护注意

- 改排名口径时，要同步检查人员页面、人员详情、比较页和导出。
- 改旧 FMS 格式时，要同时检查导入和 Legacy 导出。
- 改标签字段时，要同步检查标签 sheet 导入导出。
- 改表结构时，要同步检查 JSON 备份字段。
